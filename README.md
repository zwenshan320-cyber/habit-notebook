# 日常习惯记录本

一个适配手机的个人习惯与备忘记录网页，可添加习惯、记录好习惯和坏习惯、按周调整习惯顺序，并按日期记录备忘。

## 本地预览

用浏览器打开 `index.html` 即可体验。作为安装到手机主屏幕的网页应用时，请通过 HTTPS 网址访问。

## 数据保存

记录保存在当前浏览器的本地存储中。不同设备或浏览器入口之间不会自动同步；请使用应用内的“备份”页导出和导入 JSON 备份。

## 部署

`index.html`、`app.js`、`style.css`、`manifest.json`、`sw.js` 与 `icon.svg` 是静态网页文件。将它们作为一个文件夹部署到支持静态文件的网页托管服务即可。
